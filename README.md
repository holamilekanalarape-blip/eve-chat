# Eve

A local Eve chat: streaming replies, sidebar history, sample weather, trip planning, and memory that stays in the browser.

Notion, Linear, and Sentry are not connected. Weather answers are sample data, not a live forecast.

## Run

```bash
npm install
npm run dev
```

The dev server listens on port 8080.

Chats and memory are stored in the browser (`localStorage`). There is no account or payment flow in this app.
